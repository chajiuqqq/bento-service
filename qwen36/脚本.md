打bento
```
bentoml build --arg-file bento_args.yaml 
```


容器化
```
# 正常方式
bentoml containerize qwen3:8b

# 设置代理方式
bentoml containerize --opt build-arg=http_proxy=http://192.168.39.240:7890  --opt build-arg=https_proxy=http://192.168.39.240:7890  qwen3:8b 
```


开发模式

```
 FLASHINFER_DISABLE_VERSION_CHECK=1 CUDA_VISIBLE_DEVICES=1 bentoml serve --arg-file bento_args.yaml --port 3002
 ```

启动容器
```
docker run -it --rm --name bento-qwen3-8b   --gpus '"device=1"'   --shm-size=16gb   -v /models:/models   -p 3300:3000   qwen3:8b
```
